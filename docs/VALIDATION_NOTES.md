# Validation notes against the supplied April 2026 outputs

The cleaned code was reviewed against the five supplied intermediate/final files. The aim is to preserve the final analytical structure while making hidden/manual transformations explicit.

## Observed pipeline behavior

- The configured list contains **34 ClinPGx genes**.
- The supplied Step-1 and Step-2 CSVs contain **26 genes**. The genes absent from those files are: `ABCG2`, `CACNA1S`, `CFTR`, `DPYD`, `IFNL3`, `MT-RNR1`, `RYR1`, and `VKORC1`.
- The supplied Step-3 clinical-annotation workbook contains **12 genes**.
- The supplied merged Step-4 and final Step-5 workbooks contain **28 genes**. The six configured genes absent from the final workbook are: `ABCG2`, `CACNA1S`, `CFTR`, `DPYD`, `IFNL3`, and `RYR1`.

Absence from a supplied output is documented here; it is not interpreted as biological absence or lack of ClinPGx/CPIC relevance.

## Code issues corrected

1. **ClinPGx header normalization.** The original Step-1 rename rule looked for `CPIC FunctionLearn more about CPIC allele functions`, while the supplied CSV actually contains `CPIC FunctionLearn more about allele functions`. This left a duplicate, entirely empty `CPIC FUNCTION from ClinPGx` column. The cleaned scraper normalizes headers by prefix.
2. **Repeated configuration.** The gene list and CPIC URLs now live in `config.py`.
3. **Fixed sleeps.** Selenium fixed waits were replaced with explicit page-ready/content waits where possible.
4. **Merge-key cleanup.** `Gene`/`Variant` normalization uses pandas nullable string dtype.
5. **Manual final-workbook edits.** Project-specific curation is supported through optional local CSVs.
6. **GRCh38 definition cleanup.** Repeated long ClinPGx boilerplate is shortened to `Assume to be on GRCh38 assembly`.
7. **Manual HGVS override.** The final workbook contains an HGVS value for `VKORC1 rs61742245` absent from the supplied Step-4 workbook; the pipeline supports this as an explicit local override.
8. **Filtered sheet.** The original Step-5 script generated only one sheet, whereas the final workbook has `All VIP genes`, `Filtered alleles`, and `Legend`.

## Deterministic Step-4 validation

The cleaned Step-4 script was run against the supplied April Step-2 and Step-3 files. It reproduced the supplied Step-4 workbook **cell-for-cell**, with **1,075 rows × 25 columns**.

## Final-workbook-only MT-RNR1 rows

The supplied final `All VIP genes` sheet contains **24 MT-RNR1 variant rows** that are not present in the supplied Step-4 workbook. The uploaded original Step-5 script uses a left join from Step 4 to the CPIC table, so those rows cannot be generated by that script alone. They are therefore treated as downstream/manual curation and are not embedded in the public code or templates.

## Important reproducibility note

ClinPGx and CPIC `current` allele-functionality files are living resources. Re-running the repository later can legitimately produce different data from the April 2026 snapshot. For a manuscript/audit trail, retain the original April source downloads and generated outputs separately from the code repository.
